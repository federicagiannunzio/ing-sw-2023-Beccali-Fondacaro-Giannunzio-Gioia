## JAR
We generated 3 different jar files:
- Server.jar
- Client.jar
- Gui.jar
You can run them through powershell using the following commands:
java -jar Server.jar
java -jar Client.jar
java -jar Gui.jar
Be sure to be in the same directory as the files when you try to run them.
